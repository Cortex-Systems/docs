You can modify the Cortex PQM configuration directly in the browser using the built-in online editor, or you can download the current config file, edit it in any text editor, and re-upload it. Both approaches produce the same result — choose the one that fits your workflow.

## Option 1: Online editor (web interface)

The online editor is the quickest path for small, targeted changes. It loads the current configuration directly in the browser, so there is nothing to download or re-upload.

<Steps>
  <Step title="Open the device web page">
    Navigate to the device's IP address in your browser (for example, `http://192.168.1.100`).
  </Step>
  <Step title="Open the editor">
    Go to **Settings → Configuration → Edit**. The built-in JSON editor loads with the current configuration file.
  </Step>
  <Step title="Make your changes">
    Modify the values you want to update directly in the editor. The interface highlights syntax errors in real time so you can catch problems before saving.
  </Step>
  <Step title="Save the configuration">
    Click **Save**. The device validates the updated JSON and applies the new settings immediately. A confirmation message confirms the save was successful.
  </Step>
</Steps>

## Option 2: Offline editing

Offline editing gives you the full power of a desktop text editor — useful for larger edits, applying the same config to multiple devices, or keeping configurations under version control.

<Steps>
  <Step title="Download the current configuration">
    Use the REST API to save the active configuration to a local file:

    ```bash
    curl http://192.168.1.100/api/config -o config.json
    ```

    Replace `192.168.1.100` with your device's IP address. The command saves the current configuration as `config.json` in the current directory.
  </Step>
  <Step title="Open the file in a text editor">
    Open `config.json` in any text editor. Options include VS Code, Notepad++, Sublime Text, or even the basic system notepad — any editor that saves plain text files works.
  </Step>
  <Step title="Edit the desired fields">
    Change the values you need. Be careful to preserve the JSON structure: keep all keys in double quotes, avoid trailing commas, and ensure all braces and brackets are balanced.
  </Step>
  <Step title="Validate the file">
    Before re-uploading, validate the file to catch any syntax errors introduced during editing. Paste the contents into an online validator or use your editor's built-in JSON linting.
  </Step>
  <Step title="Re-upload the configuration">
    Upload the edited file using either the web interface or the REST API. See [Uploading Configuration Files](/configuration/uploading-files) for detailed instructions on both methods.
  </Step>
</Steps>

<Tip>
  VS Code provides real-time JSON validation, inline error highlighting, and auto-formatting out of the box — making it one of the best free options for editing Cortex PQM configuration files. Press `Shift+Alt+F` (Windows/Linux) or `Shift+Option+F` (macOS) to auto-format the file at any time.
</Tip>

<Note>
  When editing offline, always start from a freshly downloaded copy of the device's current configuration rather than an old local copy. This ensures you are not accidentally overwriting settings that were changed since your last download.
</Note>
