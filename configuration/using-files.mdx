title: "Using Configuration Files on the Cortex CSM"
sidebarTitle: "Using Files"

Configuration files are plain JSON text files stored directly on the Cortex CSM. Every operational setting from network parameters to circuit labels lives inside this single file, making it easy to back up, version control, and replicate across multiple devices.

## File format and loading

Configuration files must be **valid JSON**. The most common mistakes that produce invalid JSON are:

- Trailing commas after the last item in an object or array
- Unquoted key names (all keys must be in double quotes)
- Single quotes used instead of double quotes around strings
- Missing or mismatched curly braces `{}` or square brackets `[]`

<Tip>
  Before uploading a config file, paste its contents into a free online JSON validator (such as [jsonlint.com](https://jsonlint.com)) to catch syntax errors instantly.
</Tip>

## File structure

The configuration is organized into top-level objects, each grouping related settings. The example below shows a typical configuration covering network and device identity.

```json Cortexsettings ip.json
{
  "network": {
    "dhcp": true,
    "ip": "192.168.1.100",
    "subnet": "255.255.255.0",
    "gateway": "192.168.1.1",
    "dns": "8.8.8.8"
```

<Tip>
  You do not need to include every object in your config file. You can upload a partial file that changes only the settings you care about.
</Tip>
