The Cortex PQM stores all of its operational settings in JSON configuration files on the device itself. Adjusting these files is how you tailor the device to your installation — from naming circuits and setting CT ratios to defining network parameters and measurement options.

## How configuration works

Every time the Cortex PQM starts up, it reads the active configuration file and applies those settings. You can modify the configuration in two ways:

- **Upload a new config file** — prepare a JSON file on your computer, then push it to the device via the web interface or REST API.
- **Edit in-place via the web interface** — use the built-in editor at the device's IP address to change values directly without downloading a file.

Most settings take effect immediately after you apply a new configuration. A small number of low-level settings (such as sampling rate changes) require a device reboot to take effect; the web interface will prompt you when a reboot is needed.

## What you can configure

The configuration file controls every major aspect of device behavior:

| Category | Settings |
|---|---|
| **Network** | IP address, subnet mask, gateway, DNS, DHCP on/off, hostname |
| **Device info** | Human-readable device name, physical location, timezone |
| **Circuits** | Circuit names and labels, CT ratios, phase assignment, enable/disable |
| **Measurement** | Wiring configuration type, line frequency, sampling rate |

<Tip>
  Always download and save a copy of your current configuration file before making changes. This gives you a known-good backup to restore if something goes wrong.
</Tip>
