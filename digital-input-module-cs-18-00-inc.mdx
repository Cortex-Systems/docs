## **Connecting the Digital Input Module to the Meter**

<Steps>
  <Step title="Connect to the AUX port">
    Connect the **IN** port of the first module to the monitor's **AUX port** using a standard ethernet cable. Do **not** connect it to the Flex Ports.
  </Step>
  <Step title="Daisy-chain additional devices">
    The first modules **OUT** port can then be connected to the **IN** port of the next module.

    ![Image](/images/image-5.png "Image")
  </Step>
  <Step title="Verify communication">
    When the module is connected to the monitor, the green LED on the card blinks to show that it is communicating.
  </Step>
</Steps>

#### **Wiring the Inputs**

Dry contacts are wired to the removable 3.5mm connectors. Each Digital Input card provides 18 input positions.

- The inputs sense voltage-free dry contacts, registering a closed contact when the resistance between the contacts falls below 1k Ohms.
- The second pin on each terminal is common. When running a shared common wire between multiple contacts, always land the common conductor on the second pin.

#### **Verifying Operation**

Once the monitor is energized, a flashing green LED on the module indicates normal operation.

### **Digital Input Module Registers**

![Image](/images/image-3.png "Image")

Each connector position corresponds to a fixed register, advancing sequentially with the input number. Module numbering follows the installation sequence: the module connected directly to the meter is Module 1, the next module in the chain is Module 2, and so on.

#### **Individual Input Registers**

Each module reports the state of its 18 inputs in 18 consecutive registers, where 0 = open and 1 = closed. Module 1 begins at register 2046, and each additional module is offset by a further 49 registers.

| Module | Registers (Inputs 1-18) |
| :-- | :-- |
| 1 | 2046-2063 |
| 2 | 2095-2112 |
| 3 | 2144-2161 |
| 4 | 2193-2210 |
| 5 | 2242-2259 |
| 6 | 2291-2308 |
| 7 | 2340-2357 |
| 8 | 2389-2406 |

To locate a single input, add the input number less one to the module’s first register. For example, Input 5 on Module 3 is register 2144 + 4 = 2148.

#### **Block Reads**

Each module also reports all 18 inputs as a packed two-register block, allowing the entire module to be polled in a single transaction. Inputs 1 through 16 are returned in the first register as bits 0 through 15; inputs 17 and 18 are returned in the second register as bits 0 and 1.

| Module | Inputs 1-16 | Inputs 17-18 |
| :-- | :-- | :-- |
| 1 | 2001 | 2002 |
| 2 | 2003 | 2004 |
| 3 | 2005 | 2006 |
| 4 | 2007 | 2008 |
| 5 | 2009 | 2010 |
| 6 | 2011 | 2012 |
| 7 | 2013 | 2014 |
| 8 | 2015 | 2016 |
