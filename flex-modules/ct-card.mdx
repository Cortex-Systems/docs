    #### **24 Circuit Current Sensor High Resolution Data**

    The Cortex CS24-33-CTC supports 24 × 0.33V current transformers per module, with a total of eight modules or 192 circuits per monitor. Unlike other multi-circuit devices, the CS24-33-CTC can support dual voltage references when used with the dual input Cortex CSM-2-00, allowing a single module to support primary and secondary measurements on PDUs or other dual voltage equipment.

### **Easy to Install / Easy to Use**

Configuration is easy using a graphical layout tool. Circuit information is displayed exactly according to the PDU or gear layout, using customizable screens with friendly name assignments per circuit.

<Card title="**Features**">
  - Ultra precise 0.2% native accuracy
  - High-resolution current sampling per channel
  - User friendly graphical configuration and display
  - Universal 0.33 V current transformer input
  - 24 circuits per CT module, with up to eight modules per monitor
  - Individual voltage assignment per channel (when using dual input monitor)
  - Daisy chain to a second CT module to avoid excess wiring
  - Intelligent circuit creation allows accurate aggregation of circuits to report breaker or panel level data
  - Compact size with user friendly plug-in headers
  - Mix any variety of CT types
</Card>

## **Connectivity**

- Connects to the Cortex CSM-1-00 or CSM-2-00 using standard Ethernet cables up to 100 ft (33 m)
- Current transformers are automatically corrected for reversed polarity or orientation, simplifying installation and preventing costly mistakes
- Up to two modules may be daisy chained to each of the four Flex Ports using standard Ethernet cable

![](https://manula.r.sizr.io/large/user/23498/img/dual-voltage-2.png)

#### **Auto CT Correction**

- **Polarity correction** – reversed CT wiring polarity is corrected automatically
- **Orientation correction** – CTs installed facing the wrong direction are corrected automatically

### **Dual Voltage Assignment per Circuit**

When used with the CSM-2-00 dual input monitor, each circuit can be assigned to either the primary or secondary voltage input, allowing a single monitor and CT module to be used for both PDU input and output. Dual input RPPs can also use this feature with CT strips.

![](https://manula.r.sizr.io/large/user/23498/img/connect.png)

#### **Assign Channels to Specific Voltage Sources**

- **Dynamic voltage assignment** – assign any circuit to either voltage input (Voltage Input 1 or Voltage Input 2), e.g. PDU Input and PDU Output

#### **Group Channels to Represent Total Circuit Data**

- **Flex Meter** – circuits can be assigned to a “Flex Meter” and present data as a breaker
- **Aggregate Meter** – sum large groups of circuits to create an Aggregate Meter in place of current transformers
