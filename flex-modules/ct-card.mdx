**CS24-33-CTC — 24 Circuit Current Sensor, High Resolution Data**

The Cortex CS24-33-CTC supports 24 x 0.33 V current transformers per module, with a total of eight modules or 192 circuits per monitor. The CS24-33-CTC can support dual voltage references when used with the dual input Cortex CSM-2-00, allowing a single module to support primary and secondary measurements on PDUs or other dual voltage equipment.

Configuration uses a graphical layout tool. Circuit information is displayed according to the PDU or gear layout, using customizable screens with friendly name assignments per circuit.

## Features

- 0.2% native accuracy
- High-resolution current sampling per channel
- Graphical configuration and display
- Universal 0.33 V current transformer input
- 24 circuits per CT module, with up to eight modules per monitor
- Individual voltage assignment per channel (when using the dual input CSM-2-00)
- Daisy chain to a second CT module to avoid excess wiring
- Circuit aggregation to report breaker or panel level data
- Compact size with plug-in headers
- Mix any variety of CT types

## Connectivity

- Connects to the Cortex CSM-1-00 or CSM-2-00 using standard Ethernet cables up to 100 ft (33 m).
- Up to two modules may be daisy-chained to each of the four Flex Ports: 24 CTs per card, 48 CTs per Flex Port, 192 circuits per monitor.
- Connect the Flex Port to the module's **IN** port; connect **OUT** to the **IN** port of the second module.
- Each CT connects to a 2-pin 3.5 mm screw terminal header (16–24 AWG wire).

<Warning>
  Connect CT modules to a Flex Port only. Do not connect them to the AUX port.
</Warning>

## Auto CT Correction

- **Polarity correction** — reversed CT wiring polarity is corrected automatically.
- **Orientation correction** — CTs installed facing the wrong direction are corrected automatically.

## Setting CT Size

CT size must be set for each channel, either in the web console or by configuration file upload. Over the REST API, CT size is written per circuit with the `ctSize` key:

```json
POST /configSettings
{ "ctSize": { "circuit_1": 200, "circuit_7": 400 } }
```

## Dual Voltage Assignment per Circuit

When used with the CSM-2-00 dual input monitor, each circuit can be assigned to either the primary or secondary voltage input (Voltage Input 1 or Voltage Input 2), allowing a single monitor and CT module to be used for both PDU input and output. Dual input RPPs can also use this feature with CT strips.

## Grouping Channels

- **Flex Meter** — circuits can be assigned to a Flex Meter (up to 3 circuits, one per phase) and present data as a breaker.
- **Aggregate Meter** — sum large groups of circuits to create an Aggregate Meter.
