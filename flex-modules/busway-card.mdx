## System Architecture

A Cortex busway system uses a single head end monitor installed in a tap-off or end feed. Busway cards are connected to the monitor's four Flex Ports with standard Ethernet cable in a daisy chain.

{/* IMAGE: busway-system-architecture.png — Flex Ports, 8 cards per port, 6 circuits per card, auto CT correction */}

### Auto CT Correction

- **Polarity correction**: reversed CT wiring polarity is corrected automatically.
- **Orientation correction**: CTs installed facing the wrong direction are corrected automatically.

Standard CTs and intelligent CTs can be mixed on the same card.

## Intelligent Current Transformer

Busway cards are available with intelligent CTs that include a wire-free, non-contact voltage field sensor. This is a commonly accepted replacement for circuit breaker auxiliary status contacts.

{/* IMAGE: intelligent-ct.png */}

- Detects the voltage field in the conductor, even under no-load conditions
- Instantly detects tripped or open circuits
- No additional hardware: the non-contact field sensor is embedded in the CT
- Available in solid and split core versions
- More cost effective than auxiliary contacts
- Highly reliable, with a full quality check based on low line voltage and smallest conductor size
- Compatible with Cortex 6-circuit busway cards and future Cortex products

## Connection Guide

![2026 09 28 11 33 10](/images/2026-09-28-11-33-10.png "2026 09 28 11 33 10")

{/* IMAGE: busway-installation-overview.png — end feed monitor, tap boxes 1–8, Flex Ports 1–4 */}

<Steps>
  <Step title="Mount a card at each tap box">
    Mount one busway card at each tap box, using either the internal or external form factor. No modification is needed to most tap-cans or end feeds. For the external mount, fit the card's chase nipple through a single knockout in the tap box.
  </Step>
  <Step title="Install the CTs">
    Place a CT on each conductor to be monitored, up to six per card. The CTs have pre-wired leads with quick-connect terminals, so they can be seated easily in congested locations. Plug each CT lead into a terminal header on the card.

    {/* IMAGE: busway-ct-installation.png */}
  </Step>
  <Step title="Connect the first card to a Flex Port">
    Run a CAT6A Ethernet cable from a **FLEX Port (1–4)** on the monitor to the **IN** port of the first card.
  </Step>
  <Step title="Daisy chain the remaining cards">
    Connect the **OUT** port of each card to the **IN** port of the next card on the same Flex Port. Up to eight cards can be chained on each Flex Port.
  </Step>
  <Step title="Repeat for the other Flex Ports">
    Start with Flex Port 1 and continue through Flex Ports 2, 3 and 4. Up to 32 cards can be connected to one monitor.
  </Step>
  <Step title="Configure the monitor">
    Set the CT size for each channel in the web console or by configuration file upload. See [Configuration](/configuration/overview) and [FLEX Port Wiring](/wiring/flex-port) for details.
  </Step>
</Steps>

<Warning>
  Connect busway cards to the monitor's Flex Ports only. Do not connect them to the AUX port or the Ethernet network ports.
</Warning>

<Note>
  The position in the daisy chain determines register assignment. Keep a record of which Busway Card is on which Flex Port and chain position.
</Note>

### Example Layout

| Flex Port | Cards in chain | Circuits |
| --- | --- | --- |
| 1 | Tap boxes 1–8 | 1–48 |
| 2 | Tap boxes 9–16 | 49–96 |
| 3 | Tap boxes 17–24 | 97–144 |
