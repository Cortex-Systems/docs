Flex Port modules connect current transformers (CTs) to your Cortex monitor. The CSM-1-00 and CSM-2-00 have **four Flex Ports**, and each port supports a daisy chain of CT strips or CT modules for up to **48 current channels**, giving up to **192 monitored circuits** per monitor.

## Available Flex Port Modules

| Module | Current channels | Aux inputs |
| --- | --- | --- |
| **24 CT Module (CS24-33-CTC)** | 24 | – |
| **21 CT Strip, 3 Aux** — 0.75 in, 1.0 in, and 18 mm spacing | 21 | 3 |
| **21 CT Strip, 3 Aux, With Voltage Presence** — 0.75 in, 1.0 in, and 18 mm spacing | 21 | 3 |
| **Multi-Card (CS12-42-5-SA1)** | See [Multi-Circuit Card](/flex-modules/multi-circuit-card) | Digital inputs, digital outputs, RTD inputs |
|  |  |  |

## Connection Guide

Flex Port modules connect to the monitor's **Flex Ports (1–4)** using a standard Ethernet cable. Do **not** connect them to the AUX port.

1. Connect the monitor's Flex Port to the **IN** port of the first module.
2. Connect the module's **OUT** port to the **IN** port of the next module on the same port.
3. When a module is connected correctly, the green LED on the module blinks to show that it is communicating.

The Flex Port a module is connected to determines its register assignment. Best practice is to start with Flex Port 1 and proceed through Flex Ports 2, 3, and 4.

## Daisy Chaining

Multiple modules can be daisy-chained from a single Flex Port, provided the total number of current channels on the port does not exceed 48. Examples of valid chains on one Flex Port:

- Two 24 CT Modules = 48 channels
- Two 21 CT Strips = 42 channels

## Connecting Current Transformers

- Use 0.333 V output CTs, connected via removable 3.5 mm terminal blocks.
- CT orientation and wiring polarity are corrected automatically.
- CT size must be set for each channel, either by configuration file upload or in the web console.
- Each terminal corresponds to a specific register, depending on the Flex Port used.
- The monitor calculates neutral current, so no neutral CT is required.

## Configuring a Flex Port

Each Flex Port is configured separately in the web console under **Configuration > Meter Config**, or in the configuration file (`panel_1` to `panel_4`). Follow the orientation and wiring diagram shown in the web console that matches your panelboard type.

| Setting | Options |
| --- | --- |
| Port Name | Up to 40 characters |
| Panel Device Type | CT Modules, CT Strips |
| Panel Type | Odd/Even, Sequential, Inline, Consecutive |
| Number of Circuits | 1–192 |
| Strip Orientation | Up, Down |
| Strip Connection to Meter | Left strip, Right strip |
| Main Connection | Mains connected to left strip, Mains connected to right strip |

## Port Status

| Value | Status |
| --- | --- |
| 0 | OK |
| 1 | Discovery |
| 2 | Invalid Config |
| 3 | Disabled |
| 4 | Unsupported Device |

The monitor also reports the number of devices connected, the total number of channels, and the type, firmware version, and serial number of each device on the port. See the [Modbus Register Map](/modbus/register-map) for register addresses.
