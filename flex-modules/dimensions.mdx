# Card Dimensions

Mount the FLEX Card Module using 35mm x 7.5mm (1.378” × 0.295”) DIN rail with a minimum length of 165mm (6.5”).

- Orient the module with the DIN clips at the bottom when possible.
- Unlock both DIN clips by pulling down prior to mounting and push up to lock after mounted.
- Ensure there is adequate bending radius for all cables when mounting.

| Module | Dimensions | Mounting |
| --- | --- | --- |
| 24 CT Module (CS24-33-CTC) | 3.42 in D x 1.84 in H x 2.82 in W | 35 mm DIN rail |

## Cabling

- Flex Port modules connect to the monitor using CAT6A ethernet cables up to 100 ft (33 m).
- Supply power for the module is integrated into the communication cable; no separate power supply is required.
- CTs connect to 3.5 mm screw terminal headers (16–24 AWG wire). Allow space in front of the module for CT wiring.
