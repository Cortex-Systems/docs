Use this page as a reference when planning enclosure space for Flex Port modules. Flex Port modules are separate DIN-rail mounted devices that connect to the monitor's Flex Ports with standard Ethernet cables, so they can be placed close to the circuits being monitored.

## Module Dimensions

| Module | Dimensions | Mounting |
| --- | --- | --- |
| 24 CT Module (CS24-33-CTC) | 3.42 in D x 1.84 in H x 2.82 in W | 35 mm DIN rail |

<Note>
Refer to the product datasheet or contact Cortex Systems for the dimensions of CT strips and the Multi-Card.
</Note>

## Cabling

- Flex Port modules connect to the monitor using standard Ethernet cables up to 100 ft (33 m). CAT 6A cable is recommended.
- Supply power for the module is integrated into the communication cable; no separate power supply is required.
- CTs connect to 3.5 mm screw terminal headers (16–24 AWG wire). Allow space in front of the module for CT wiring.
