The Multi-Card is an expansion card that combines current transformer inputs with digital inputs, digital outputs, and RTD temperature inputs. The monitor identifies it as device type **23 (`MULTI_CARD_12CT`)**.

## Connecting the Multi-Card

- Connect the Multi-Card to a **Flex Port (1–4)** using a standard Ethernet cable. Connect the Flex Port to the card's **IN** port; additional devices can be daisy-chained from **OUT** to **IN**.
- A blinking green light on the card indicates a correct connection.
- The Flex Port used determines register assignment.
- Current transformers must be 0.333 V output CTs. CT orientation and wiring polarity are corrected automatically, and CT size must be set in the web console or configuration file.

## Readings

Each Multi-Card reports:

- A digital input bitmask (`diValue`)
- A digital output bitmask (`doValue`)
- Up to 5 RTD temperature readings (°C). A value of `999.99` means the RTD sensor is not connected or is out of range.

### REST API

`GET /api/multicarddata` returns the readings for each Flex Port:

```json
{
  "data": {
    "ports": [
      { "port": 1, "status": 0, "connected": false, "cards": [] },
      { "port": 3, "status": 0, "connected": true, "cards": [
        { "device": 0, "diValue": 2, "doValue": 0,
          "rtdValues": [999.99, 999.99, 206.63, 999.99, 999.99] }
      ]},
      { "port": 4, "status": 0, "connected": false, "cards": [] }
    ],
    "multiCard12CTConnected": true
  }
}
```

`status` is a per-port status code (0 = normal). This endpoint covers only Multi-Card devices; AUX port cards are covered by `/api/auxport`.

### Modbus

Flex Port digital input, digital output, and RTD registers:

| Flex Port | Digital inputs (1–48) | Digital outputs (1–48, writable) | RTD temperature (FLOAT32) |
| --- | --- | --- | --- |
| 1 | 34000–34047 | 34048–34095 | 34096–34191 |
| 2 | 35000–35047 | 35048–35095 | 35096–35191 |
| 3 | 36000–36047 | 36048–36095 | 36096–36191 |
| 4 | 37000–37047 | 37048–37095 | 37096–37191 |

Digital input and output values: 0 = open, 1 = closed. See the [Modbus Register Map](/modbus/register-map).
