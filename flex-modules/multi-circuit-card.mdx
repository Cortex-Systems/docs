## **Connectivity**

### **Current Sensor Connections**

The Multi-Card connects to one of the four Flex Ports using Ethernet cable and may be series with other CT interface cards.

- Connects to the Cortex CSM-1-00 or CSM-2-00 using CAT6A ethernet cables up to 100’ (33m)
- Daisy chain any combination of CT interface devices for a total of up to 48 CT channels per Flex Port
- Use with standard 0.333V current transformers which are automatically corrected for reversed polarity or orientation simplifying installation and preventing costly mistakes

![](https://manula.r.sizr.io/large/user/23498/img/p2-1.png)

_Diagram: 4 Flex Ports (x192 CTs total), x48 CTs per Flex Port, 0.33V CT wiring. Auto CT Correction: polarity correction and orientation correction._

### **Digital I/O Connections**

Each card will accommodate 4 digital inputs and 2 digital outputs.

![](https://manula.r.sizr.io/large/user/23498/img/p2-2.png)

_Diagram: Flex Ports 1–4 connected via CAT 6A (100’ max), daisy-chained to other Flex Port CT devices. Digital Input X4; Digital Output X2 rated 100mA @ 30 VDC._

### **Thermal Probe Connectivity**

- Connect up to five two-wire application specific probes per card
- Available custom harness kits simplify installation

- TPS-TB-010 Tape Mount Thermal Probe Installation
- TPS-RL-010 Ring Lug Thermal Probe Installation
- TPS-CM-010 Ambient Temperature Probe

### REST API

`GET /api/multicarddata` returns the readings for each Flex Port:

```json
{
  "data": {
    "ports": [
      { "port": 1, "status": 0, "connected": false, "cards": [] },
      { "port": 3, "status": 0, "connected": true, "cards": [
        { "device": 0, "diValue": 2, "doValue": 0,
          "rtdValues": [999.99, 999.99, 206.63, 999.99, 999.99] }
      ]},
      { "port": 4, "status": 0, "connected": false, "cards": [] }
    ],
    "multiCard12CTConnected": true
  }
}
```

`status` is a per-port status code (0 = normal). This endpoint covers only Multi-Card devices; AUX port cards are covered by `/api/auxport`.

### Modbus

Flex Port digital input, digital output, and RTD registers:

| Flex Port | Digital inputs (1–48) | Digital outputs (1–48, writable) | RTD temperature (FLOAT32) |
| --- | --- | --- | --- |
| 1 | 34000–34047 | 34048–34095 | 34096–34191 |
| 2 | 35000–35047 | 35048–35095 | 35096–35191 |
| 3 | 36000–36047 | 36048–36095 | 36096–36191 |
| 4 | 37000–37047 | 37048–37095 | 37096–37191 |

Digital input and output values: 0 = open, 1 = closed. See the [Modbus Register Map](/modbus/register-map).
