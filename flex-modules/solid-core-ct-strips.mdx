Cortex CT strips are strips of solid-core current transformers for branch circuit monitoring in panelboards. Each strip provides **21 current channels and 3 aux inputs**, and connects directly to a Flex Port on the CSM-1-00 or CSM-2-00 using a standard Ethernet cable.

## Strip Variants

| Strip | CT spacing | Current channels | Aux inputs |
| --- | --- | --- | --- |
| 21 CT Strip, 3 Aux | 0.75 in, 1.0 in, or 18 mm | 21 | 3 |
| 21 CT Strip, 3 Aux, With Voltage Presence | 0.75 in, 1.0 in, or 18 mm | 21 | 3 |

Choose the CT spacing that matches the breaker pitch of the panel. Strips with voltage presence report per-circuit voltage presence, which can raise a voltage presence alarm.

## Connecting CT Strips

- Connect the strip to a **Flex Port (1–4)** using a standard Ethernet cable. Do not connect strips to the AUX port.
- Connect the Flex Port to the **IN** port of the first strip, then connect the **OUT** port of that strip to the **IN** port of the next strip.
- Up to 48 current channels are supported per Flex Port, so two 21 CT strips (42 channels) can share one Flex Port — for example, the left and right sides of a panel.
- A blinking green light on the strip indicates a correct connection.
- The Flex Port used determines register assignment. Start with Flex Port 1 and proceed through 2, 3, and 4.

## Installation

<Warning>
AC wiring has lethal voltages. Installation must be completed by a qualified person. De-energize the panel and follow all applicable lockout/tagout procedures.
</Warning>

<Warning>
  Solid-core CTs cannot be installed around a conductor that is already terminated at both ends — the conductor must pass through the CT window. Plan the installation sequence before terminating circuit conductors.
</Warning>

<Steps>
  <Step title="De-energize the panel">
    Turn off power to the panel and verify it is de-energized before proceeding.
  </Step>
  <Step title="Position the CT strips">
    Position each strip along its breaker row so that each CT aligns with its breaker position.
  </Step>
  <Step title="Pass the branch conductors through the CTs">
    Pass each branch circuit conductor through its corresponding CT window, one conductor per CT. CT orientation and polarity are corrected automatically by the monitor.
  </Step>
  <Step title="Connect the strips to the Flex Port">
    Connect the Flex Port to the **IN** port of the first strip with a standard Ethernet cable, and daisy-chain the second strip from **OUT** to **IN**.
  </Step>
  <Step title="Re-energize and verify">
    Re-energize the panel and confirm the green LED on each strip is blinking.
  </Step>
</Steps>

## Configuring the Panel

In the web console, select **Configuration > Meter Config > Step 1** and configure the Flex Port the strips are connected to. Follow the orientation and wiring diagram shown in the web console that matches your panelboard type.

| Setting | Options |
| --- | --- |
| Panel Device Type | CT Strips |
| Panel Type | Odd/Even, Sequential, Inline, Consecutive |
| Number of Circuits | Number of circuits on the port |
| Strip Orientation | Up, Down |
| Strip Connection to Meter | Left strip, Right strip |
| Main Connection | Mains connected to left strip, Mains connected to right strip |

Set the CT size for each circuit in the web console or configuration file. See [FLEX Port Modules](/flex-modules/overview).
