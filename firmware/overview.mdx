Keeping your Cortex PQM (CSM-1-00 / CSM-2-00) firmware up to date ensures you benefit from the latest bug fixes, new features, and improvements. Each firmware release may include enhancements to power quality calculations, Modbus/REST API behavior, and peripheral support.

## Checking Your Current Firmware Version

Before deciding whether an update is needed, confirm the version currently running on your device.

**Via the web interface:**

1. Navigate to your device's IP address in a browser.
2. Go to **Settings → About**.
3. The firmware version is displayed under **Device Information**.

## Update Methods

Two methods are available for updating firmware on the Cortex PQM:

**Use the USB method** when the device is deployed in a location without network access, or when you are performing an on-site field update and a laptop is unavailable for a network-based workflow.

**Use the network (OTA) method** when the device is already connected to Ethernet. This method requires no physical access to the device and is well-suited for updating multiple units remotely or automating updates via the REST API.

<Warning>
  Do not power off the device during a firmware update. Interrupting the update process may corrupt the firmware and require a recovery procedure. Wait for the Status LED to return to a steady green before disconnecting power.
</Warning>
