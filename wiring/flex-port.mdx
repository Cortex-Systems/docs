Flex Port wiring connects CT modules, CT strips, and Multi-Cards to the monitor, and connects current transformers to those modules. Without correctly connected and configured CTs, the monitor cannot calculate current, power, or energy.

## Connecting Modules to the Flex Ports

- Connect CT interface devices to **Flex Ports 1–4** using standard Ethernet cables (up to 100 ft / 33 m; CAT 6A recommended). Do not connect them to the AUX port or the Ethernet ports.
- Connect the Flex Port to the **IN** port of the first device, then connect the **OUT** port of that device to the **IN** port of the next device.
- Up to 48 current channels are supported per Flex Port (for example, two 24 CT modules or two 21 CT strips).
- A blinking green light on each device indicates a correct connection.
- The Flex Port used determines register assignment. Start with Flex Port 1 and proceed through 2, 3, and 4.

## Supported CTs

| CT output type | Connection |
| --- | --- |
| 0.333 V output | Removable 3.5 mm headers (2-pin screw terminal per CT, 16–24 AWG) |

Any variety of 0.333 V CT types can be mixed on a module.

## Wiring CTs to a CT Module

<Steps>
  <Step title="Install the CT">
    Install the CT around the conductor to be measured.
  </Step>
  <Step title="Connect the CT leads">
    Connect the two CT leads to the 2-pin 3.5 mm header for the channel. CT orientation and wiring polarity are corrected automatically, so reversed leads or a CT facing the wrong direction do not affect readings.
  </Step>
  <Step title="Repeat for each channel">
    Repeat for each CT. Label each CT lead pair with its channel or circuit.
  </Step>
</Steps>

<Tip>
  Each terminal corresponds to a specific register, depending on the Flex Port used. Record the channel-to-circuit mapping as you wire.
</Tip>

## Wire Routing

- Route CT leads away from high-voltage conductors where possible.
- Place CT modules close to the circuits being monitored and use the Ethernet cable for the longer run to the monitor.

## Setting CT Size

CT size must be set for each channel, either in the web console or by configuration file upload. With the REST API, use the `ctSize` key with the CT rated size in amps:

```json
POST /configSettings
{ "ctSize": { "circuit_1": 100, "circuit_2": 200 } }
```

The monitor calculates neutral current, so a neutral CT is not required. Follow the orientation and wiring diagrams in the web console (**Configuration > Meter Config**) that match your panelboard type.
