The Cortex PQM CSM-1-00 and CSM-2-00 use the following connections. Read this overview to understand what each connection does and which page covers it.

## Connection Summary

| Connection | Type | Purpose |
|---|---|---|
| AC reference voltage | Terminal connector | Voltage sensing (no power draw). Volt Input 2 on CSM-2-00 only |
| DC power | DC connector | Energizes the monitor; ground (earth) for AC and DC |
| Flex Ports 1–4 | RJ45, standard Ethernet cable | CT modules, CT strips, and Multi-Cards (up to 48 current channels per port) |
| AUX port | RJ45, standard Ethernet cable | Digital input, digital I/O + serial, and thermal modules |
| Ethernet Ports 1 and 2 | RJ45 | Network: web console, REST API, Modbus TCP |

## General Wiring Safety Rules

- **AC wiring has lethal voltages.** Installation must be completed by a qualified person.
- **De-energize circuits** before making connections, and verify they are de-energized.
- **Fuse the AC reference voltage** according to code: 0.25 A up to the maximum conductor rating.
- **Comply with local electrical codes** for conductors, labeling, and overcurrent protection.
- **Use the correct RJ45 port.** Flex Ports, the AUX port, and the Ethernet ports use similar jacks. Connect Flex Port modules only to Flex Ports, AUX modules only to the AUX port, and the network only to Ethernet Port 1 or 2.

<Warning>
  AC wiring has lethal voltages. Incorrect AC wiring can result in electric shock, equipment damage, or fire.
</Warning>
