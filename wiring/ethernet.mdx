The CSM monitor has two Ethernet ports that share a common IP address. Ethernet provides access to the web console, the REST API, and Modbus TCP.

## Network Interface

| Parameter | Specification |
|---|---|
| Ports | Ethernet Port 1 and Ethernet Port 2 (RJ45), common IP address |
| Default IP address | 192.168.7.3 |
| Default subnet mask | 255.255.255.0 |
| Default gateway | 192.168.7.1 |
| DHCP | Disabled by default |
| Modbus TCP | Port 502, up to 15 concurrent clients |

## Physical Connection

<Steps>
  <Step title="Connect the cable">
    Connect a standard Ethernet cable to **Ethernet Port 1 or 2** on the monitor. Do not connect to a Flex Port or the AUX port — they use similar RJ45 jacks but are for Cortex modules only.
  </Step>
  <Step title="Connect to your PC or network">
    Connect the other end to your PC or network switch.
  </Step>
  <Step title="Set the PC IP address">
    The PC must be on the same subnet as the monitor. For a monitor at the default address, set a static IP on the PC such as `192.168.7.10` with subnet mask `255.255.255.0`, and make sure no other device uses the same address.
  </Step>
  <Step title="Open the web console">
    Enter the monitor's IP address in a browser, for example `http://192.168.7.3`. The main page shows device information and the installed firmware version.
  </Step>
</Steps>

## Recovering a Lost IP Address

1. Insert a USB drive (32 GB or less, FAT32) into the monitor's USB port while it is powered.
2. Wait about 5 seconds.
3. Remove the drive and open the IP settings file on a PC. It lists the monitor's current IP settings.

If the IP address cannot be recovered this way, hold the reset button for more than 10 seconds to restore the default IP address `192.168.7.3`. This also restores **all** other settings to factory default (solid orange LED). Download the configuration first if possible.

## Changing the Network Settings

Set the IP address, subnet mask, gateway, DHCP, DNS, and NTP in the web console, or in the `ipv4` section of a configuration file:

```json Cortexsettings.json
{
  "ipv4": {
    "enable": true,
    "dhcpEnable": false,
    "address": "192.168.7.3",
    "gateway": "192.168.7.1",
    "subnetMask": "255.255.255.0",
    "dns1": "8.8.8.8",
    "dns2": "0.0.0.0",
    "ntpIpAddress": "0.0.0.0",
    "ntpURL": "time.windows.com"
  }
}
```

IP changes require a restart. The IP address must be unique on the network. See [Configuration File Definitions](/configuration/file-definitions).

## Accessing the Device

| Interface | URL |
|---|---|
| Web console | `http://{device-ip}/` |
| REST API | `http://{device-ip}/api/<endpoint>` |

A quick connectivity check is `http://{device-ip}/api/healthcheck`, which returns `"data": 1` when the monitor is reachable.

## Network Security

- HTTPS can be enabled (`httpsEnable` in `deviceConfig`) after installing a CA-signed certificate; see `GET /api/csr` in the [REST API Reference](/api/overview).
- Modbus TCP can be disabled (`modbusTCPEnable`), and Modbus TLS enabled (`modbusTLSEnable`).
- The REST API does not require authentication. Place the monitor on a trusted network and restrict access with firewall rules or VLANs.
