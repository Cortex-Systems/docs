The CSM monitor measures AC reference voltage from the panel through fused connections. The AC reference voltage inputs are for **sensing only and draw no power**; the monitor is powered from its DC connector.

<Warning>
  AC wiring has lethal voltages. Installation must be completed by a qualified person. De-energize the panel before making connections.
</Warning>

## Voltage Inputs

| Model | Voltage inputs |
| --- | --- |
| CSM-1-00 | Volt Input 1 (L1, L2, L3) |
| CSM-2-00 | Volt Input 1 and Volt Input 2 (L1, L2, L3 each) |

On the CSM-2-00, Volt Input 2 lets you monitor circuits referenced to a second voltage source, for example PDU input and PDU output.

## Fusing

Fuse the AC reference voltage according to code: **0.25 A up to the maximum conductor rating**.

<Warning>
  Never connect voltage inputs without appropriate fusing.
</Warning>

## Wiring Steps

1. De-energize the panel and verify it is de-energized.
2. Connect each phase conductor through its fuse to the corresponding terminal (L1, L2, L3) of Volt Input 1.
3. Connect the neutral, if present, to the neutral terminal of the voltage input.
4. On the CSM-2-00, wire Volt Input 2 in the same way from the second voltage source.
5. The ground (earth) connection for both AC and DC is made through the DC connector. See [DC Wiring](/wiring/dc-wiring).

## Configuring the Voltage Input

After wiring, configure each voltage input in the web console (**Configuration > Meter Config**) or in the `voltage` section of the configuration file: system voltage (line-to-line), PT ratio (`100` = 1.00), frequency, and phase rotation (ABC or ACB). Select the service type and voltage reference that match the installation.

For details on phases, measured voltages, and circuit phase assignment, see [Wiring Configurations](/csm/wiring-configurations).
