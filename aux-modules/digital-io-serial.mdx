The CS18-02-SR1 Digital I/O + Serial Module expands a single or dual input monitor with **18 dry contact inputs, 2 digital outputs, and RS-485 Modbus RTU** communications. The module auto-connects to the host monitor with no configuration required.

<Note>
  The CSM-1 or CSM-2 must have firmware version 1.9 / 2.9 or higher to communicate with this card.
</Note>

## Specifications

| Parameter | Value |
| --- | --- |
| Part number | CS18-02-SR1 |
| Digital inputs | 18 (dry contact; closed when resistance is below 1 kΩ) |
| Digital outputs | 2, rated 100 mA @ 30 VDC max. |
| Serial port | 1 x RS-485, 2-wire Modbus RTU |
| Field wiring | Removable 3.5 mm terminal blocks |
| Connection | AUX port, standard Ethernet cable up to 100 ft (33 m) |
| Current draw | 82 mA (from the AUX port 500 mA budget) |
| Maximum modules | 6 in a single-type chain (500 mA budget) |

## Connecting the Module

<Steps>
  <Step title="Connect to the AUX port">
    Connect the **IN** port of the first module to the monitor's **AUX port** using a standard Ethernet cable. Do **not** connect it to the Flex Ports.
  </Step>
  <Step title="Daisy-chain additional devices">
    Connect the module's **OUT** port to the **IN** port of the next AUX port device.
  </Step>
  <Step title="Verify communication">
    When the module is connected to the monitor, the green LED on the card blinks to show that it is communicating.
  </Step>
</Steps>

## Digital Inputs

The digital inputs are designed for voltage-free (dry) contacts. An input reads as closed when the resistance across its contacts drops below 1 kΩ. Input status can also be checked in the web console under **Data > Contacts**; closed contacts are highlighted in green.

## Digital Outputs

The digital outputs are rated for 100 mA @ 30 VDC. They can be switched by Modbus command, by `POST /configSettings` (`doData.output_N`, value 0 or 1), or manually from the web console.

## RS-485 Modbus RTU

The RS-485 port provides 2-wire Modbus RTU communications. Serial settings (slave ID, baud rate, parity, stop bits) are in the `modbus` section of the configuration file. See [Configuration File Definitions](/configuration/file-definitions).

## Data Access

### REST API

`GET /api/auxport` returns Digital I/O boards with `"deviceType": "dio"`: 18 DI channels (`"type": "di"`) and 2 relay outputs (`"type": "do"`). Values: 1 = contact closed / relay energized, 0 = open. DI channels are numbered sequentially across cards; DO channels use card-local numbering (1 and 2). A `deviceSerial` of `0` means the serial number is not programmed (common on DIO boards).

### Modbus

Cards are numbered by their position in the AUX chain, starting with the card plugged directly into the AUX port (Card 1). Every device on the AUX port counts as a card, including Thermal modules.

- **Individual inputs:** Card 1 inputs 1–18 are registers 2046–2063 (0 = open, 1 = closed).
- **Block read:** Card 1 uses registers 2001–2002 (register 2001 bits 0–15 = inputs 1–16; register 2002 bits 0–1 = inputs 17–18). Each following card uses the next two registers, through Card 8 at 2015–2016.
- **Digital outputs:** registers 2692–2883 (writable, 0 = open, 1 = closed).

See the [Modbus Register Map](/modbus/register-map).
