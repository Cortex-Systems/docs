The AUX port on the CSM device accepts plug-in expansion modules that extend its capabilities with digital I/O and temperature sensing. Each module connects directly to the AUX port header and is recognized automatically by the device firmware, making it straightforward to tailor your Cortex PQM installation to the specific monitoring and control requirements of your site.

## Available AUX Modules

| Module | Part Number | Primary Function |
|---|---|---|
| Digital Input Module | CS18-00-INC | Dry contact status inputs |
| Digital I/O + Serial Module | CS18-02-SR1 | RS-485 serial communication combined with digital input and output channels |
| Thermal Module | CS18-01-TMP | Multi-channel temperature monitoring via RTD probe |

<Note>
  Only one AUX module can be installed at a time. If you need to swap modules, power off the CSM device before disconnecting or connecting any AUX module to ensure safe handling.
</Note>
