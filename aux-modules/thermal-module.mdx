Part Number: CS18-01-TMP | 18 CHANNEL THERMAL CARD

## **Product Information**

The Cortex Thermal Card brings precise, flexible temperature monitoring to your Cortex system. It interfaces with Cortex’s thermal probes, including four application-specific probe types built for different monitoring needs.

  <Column>
    <img

  <Column>
    - Thermal Cards connect to the Cortex CSM-1-00 or CSM-2-00 using standard ethernet cables up to 100’ (33m). CAT6A shielded cable recommended.
    - Interfaces with Cortex thermal probes (PT1000 RTD sensors)
    - Application specific thermal probes available in four styles
    - Probes may be assigned friendly names under the configuration utility
    - Thermal probe inputs are also available on the Multi-Card (a combination CT, DI/DO, thermal card) and connect to the screw terminal plug headers; non polarized.
  </Column>
</Columns>

<Danger>
  AC wiring has lethal voltages; installation must be completed by a qualified person.
</Danger>

## Specifications

| Parameter | Value |
| --- | --- |
| Part number | CS18-01-TMP |
| RTD sensor channels | 18, plus board temperature (channel 19) |
| Temperature unit | °C |
| Connection | AUX port, standard Ethernet cable up to 100 ft (33 m) |
| Current draw | 50 mA (from the AUX port 500 mA budget) |
| Maximum modules | 8 in a single-type chain |
