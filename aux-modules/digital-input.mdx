The CS18-00-INC Digital Input Module adds **18 dry contact inputs** per module to the Cortex monitor. The module automatically connects to the CSM-1-00 or CSM-2-00 and requires no configuration.

## Specifications

| Parameter | Value |
|---|---|
| Part number | CS18-00-INC |
| Inputs | 18 dry contact inputs |
| Input type | Voltage-free (dry) contacts; closed when resistance is below 1 kΩ |
| Field wiring | Removable 3.5 mm terminal blocks |
| Connection | AUX port, standard Ethernet cable up to 100 ft (33 m) |
| Current draw | 125 mA (from the AUX port 500 mA budget) |
| Maximum modules | 4 in a single-type chain (500 mA budget) |

## Connecting the Module

<Steps>
  <Step title="Connect to the AUX port">
    Connect the **IN** port of the first module to the monitor's **AUX port** using a standard Ethernet cable. Do not connect the module to a Flex Port.
  </Step>
  <Step title="Daisy-chain additional modules">
    Connect the **OUT** port of each module to the **IN** port of the next module.
  </Step>
  <Step title="Verify operation">
    Once the monitor is energized, a blinking green LED on the module indicates normal operation.
  </Step>
</Steps>

## Wiring

Dry contacts are wired to the removable 3.5 mm connectors. The inputs sense voltage-free dry contacts and register a closed contact when the resistance between the contacts falls below 1 kΩ. No external voltage source is required.

Keep field wiring away from high-voltage conductors.

## Channel Names

Assign friendly names to each channel in the web console, or with `POST /configSettings` using `diName.channel_N`.

## Data Access

### REST API

`GET /api/auxport` returns all AUX cards. Digital input cards have `"deviceType": "di"`; each input channel has `"type": "di"` and `value` 1 = closed, 0 = open. DI channels are numbered sequentially across cards (card 1 = 1–18, card 2 = 19–36, …).

### Modbus

Module numbering follows the chain sequence: the module connected directly to the monitor is Module 1.

| Module | Individual inputs 1–18 (0 = open, 1 = closed) | Block read: inputs 1–16 (bits 0–15) | Block read: inputs 17–18 (bits 0–1) |
| --- | --- | --- | --- |
| 1 | 2046–2063 | 2001 | 2002 |
| 2 | 2095–2112 | 2003 | 2004 |
| 3 | 2144–2161 | 2005 | 2006 |
| 4 | 2193–2210 | 2007 | 2008 |

Register 2000 reports the number of digital input cards connected. See [Digital Input Module: CS18-00-INC](/digital-input-module-cs-18-00-inc) and the [Modbus Register Map](/modbus/register-map).
