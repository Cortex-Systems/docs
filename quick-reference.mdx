This page provides a condensed reference for the Cortex PQM CSM-1-00 and CSM-2-00 — covering hardware specifications, LED indicator meanings, port descriptions, and supported wiring configurations. Keep this page handy during installation and commissioning. For full wiring diagrams and detailed configuration procedures, refer to the Device Overview and Configuration Guide sections.

<Warning>
  Before working inside an energized panel, **de-energize all circuits** or follow an approved energized electrical work procedure in accordance with NFPA 70E or your applicable local safe work standard. Failure to do so exposes you to arc flash and electric shock hazards that can cause serious injury or death.
</Warning>

## Device Specifications

| Parameter | CSM-1-00 | CSM-2-00 |
| --- | --- | --- |
| **Voltage input channels** | 3 phases + neutral | 3 phases + neutral |
| **Voltage input range** | 208/240/480 VAC (nominal) | 208/240/480 VAC (nominal) |
| **Current inputs** | Via CT clamp (external) | Via CT clamp (external), 1 per phase |
| **CT input signal** | 0.333 mV (industry standard) | 0.333 mV (industry standard) |
| **Supported CT ratios** | Software configurable | Software configurable |
| **Auxiliary power supply** | 12–24 VDC, ±10% | 12–24 VDC, ±10% |
| **Power consumption** | ≤ 5 W (device only) | ≤ 6 W (device only) |
| **Communication** | Ethernet 10/100BASE-T, RJ45 | Ethernet 10/100BASE-T, RJ45 |
| **Protocols** | REST (HTTP/HTTPS), Modbus TCP | REST (HTTP/HTTPS), Modbus TCP |
| **Mounting** | 35 mm DIN rail (EN 60715) | 35 mm DIN rail (EN 60715) |
| **Operating temperature** | −10 °C to +60 °C | −10 °C to +60 °C |
| **Storage temperature** | −20 °C to +70 °C | −20 °C to +70 °C |
| **Relative humidity** | 5–95% RH, non-condensing | 5–95% RH, non-condensing |
| **Pollution degree** | Pollution Degree 2 | Pollution Degree 2 |
| **Enclosure** | IP20 (panel-mount) | IP20 (panel-mount) |

<Note>
  Voltage input ranges reflect nominal system voltages. Always verify that the device's rated input range matches your local supply voltage before connecting. Both models support wye (star) and delta wiring configurations. Select the correct configuration in the device settings.
</Note>

| Color / State | Meaning |
| --- | --- |

| **Fast blink blue** (4 Hz) | Firmware update in progress. Do not remove power |

## Port Descriptions

### DC Power Input

A 2-position screw terminal block accepts the 12–24 VDC auxiliary supply. The positive (+) terminal is marked on the device housing. Polarity protection is provided, but verify polarity before applying power.

### Voltage Input Terminals

Screw terminal connections for line voltage sensing. Both models provide terminals for all three phases and neutral. The CSM-2-00 provides an additional voltage input.

### CT Clamp Inputs

Each base channel has a corresponding CT input terminal pair (signal + and −). Connect the CT clamp's output leads to these terminals.

### FLEX Port Slots

The four Flex ports accept modules with current monitoring capabilities.

### AUX Port

The AUX port accepts plug-in accessory modules:

| Module | Model | Function |
| --- | --- | --- |
| **Digital input module** | CS18-00-INC | Digital inputs |
| **Digital I/O + serial module** | CS18-02-SR1 | Digital inputs, digital outputs, and RS-485 serial interface |
| **Thermal module** | CS18-01-TMP | RTD Temperature Probe |

### Ethernet (RJ45)

Standard RJ45 jack for 10/100BASE-T Ethernet. Connects to your local network switch or router. Supports auto-negotiation and auto-MDI/MDIX (crossover cables are not required).
