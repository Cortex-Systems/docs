This page provides a condensed reference for the Cortex PQM CSM-1-00 and CSM-2-00: capabilities, status LED indications, ports, and default settings. For full procedures, see the [Quick Start Guide](/quick-start-guide) and the [Configuration Guide](/configuration/overview).

<Danger>
  AC wiring has lethal voltages. Installation must be completed by a qualified person.
</Danger>

## Device Capabilities

| Parameter | CSM-1-00 | CSM-2-00 |
| --- | --- | --- |
| **Voltage inputs** | 1 (Volt Input 1) | 2 (Volt Input 1 and Volt Input 2) |
| **AC reference voltage** | Sensing only, no power draw | Sensing only, no power draw |
| **Current channels** | Up to 192 (4 Flex Ports × 48 channels) | Up to 192 (4 Flex Ports × 48 channels) |
| **CT type** | 0.333 V output CTs, connected to CT modules or CT strips | 0.333 V output CTs, connected to CT modules or CT strips |
| **Neutral current** | Calculated; no neutral CT required | Calculated; no neutral CT required |
| **AUX port** | Up to 8 daisy-chained modules (500 mA total budget) | Up to 8 daisy-chained modules (500 mA total budget) |
| **Ethernet** | 2 ports, common IP address | 2 ports, common IP address |
| **Protocols** | Web console, REST API (HTTP/HTTPS), Modbus TCP (port 502) | Web console, REST API (HTTP/HTTPS), Modbus TCP (port 502) |
| **USB port** | Configuration, firmware updates, IP settings readout | Configuration, firmware updates, IP settings readout |
| **Power** | DC power source; ground (earth) for AC and DC via the DC connector | DC power source; ground (earth) for AC and DC via the DC connector |

## Default Network Settings

| Setting | Default |
| --- | --- |
| IP address | 192.168.7.3 |
| Subnet mask | 255.255.255.0 |
| Gateway | 192.168.7.1 |
| DHCP | Disabled |
| Modbus TCP port | Port 502 (up to 15 concurrent clients) |

The PC or polling device must be on the same subnet as the monitor (for example, 192.168.7.xxx).

## Ports

### DC Power

The DC connector energizes the monitor. The ground (earth) connection for both AC and DC is made through the DC connector.

### AC Reference Voltage

Voltage sensing inputs (sensing only, no power draw). Fuse according to code, 0.25 A up to the maximum conductor rating. Volt Input 2 is available on the CSM-2-00 only.

### Flex Ports (1–4)

Four RJ45 Flex Ports connect CT modules, CT strips, and Multi-Cards using standard Ethernet cables. Modules can be daisy-chained (IN/OUT) for up to 48 current channels per port. The Flex Port used determines register assignment; start with Flex Port 1 and proceed through 2, 3, and 4.

### AUX Port

The AUX port connects daisy-chained interface modules using standard Ethernet cables:

| Module | Model | Function |
| --- | --- | --- |
| **Digital input module** | CS18-00-INC | 18 dry contact inputs |
| **Digital I/O + serial module** | CS18-02-SR1 | 18 dry contact inputs, 2 digital outputs, RS-485 Modbus RTU |
| **Thermal module** | CS18-01-TMP | RTD temperature sensors |

<Warning>
  Do not connect Flex Port modules to the AUX port, or AUX modules to a Flex Port.
</Warning>

### Ethernet Ports 1 and 2

Two RJ45 Ethernet ports share a common IP address. Connect either port to a PC or network. Do not confuse the Ethernet ports with the four similar-looking Flex Port RJ45 jacks.

### USB Port

Accepts a USB drive of 32 GB or less, formatted FAT32. Used to load configuration files and firmware, and to read the monitor's IP settings (insert a drive while powered and wait about 5 seconds).
