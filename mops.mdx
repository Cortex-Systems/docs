  <Accordion title="**Downloading Configuration Files**" icon="download">
    The configuration of a Cortex monitor can be downloaded as a JSON file. The file can be kept as a backup, edited, and uploaded to other monitors to speed up deployment across multiple panels.

    You can edit the configuration file so it contains only the sections you need. If you remove device-specific settings such as the IP address and device name, the same file can be used on multiple monitors without changing each monitor’s network settings or name.

    #### **Downloading from the Web Console**

    1. Open the web console. See **Connecting to the Web Console** below.
    2. Select System on the left hand menu.
    3. Under the Miscellaneous box, select Download Settings.
    4. The file is saved to a USB drive if one is inserted in the monitor, or downloaded directly to the PC.

    #### **File Naming**

    The downloaded file may be renamed, provided the name begins with one of the accepted prefixes and ends with one of the accepted extensions.

    | Accepted Prefix | Accepted Extension |
    | :-- | :-- |
    | `Cortexsettings ` | `.json` |

    Example: `Cortexsettings PDU-4B.json`

    **!**Download and store a copy of the configuration before making changes or performing a factory reset. A factory reset erases all settings.
  </Accordion>

  <Accordion title="**Editing Configuration Files**" icon="code">
    Configuration files are plain text JSON files and can be edited in any text editor. Recommended editor: [Sublime Text](https://www.sublimetext.com/). Notepad may also be used.

    <Warning>
      Do not edit configuration files in Excel or other spreadsheet programs. These can insert hidden characters and commas that corrupt the file.
    </Warning>

    #### **Editing Guidelines**

    - Maintain JSON syntax. Every opening bracket `{` must have a matching closing bracket `}`, and entries within a section are separated by commas.
    - Text values are enclosed in double quotes. Numeric and `true` / `false` values are not.
    - Keep the file name prefix and extension. See **Downloading Configuration Files** above.
    - Validate the file in a JSON checker before uploading if it has been edited by hand.

    #### **Uploading Partial Configurations**

    A file does not need to contain the full configuration. Any section omitted from the file is left unchanged on the monitor. This allows a single setting to be pushed to many monitors without overwriting their other settings.

    For example, to change only the device name, include only the `deviceConfig` section:

    ```text
    {
      "deviceConfig": {
        "deviceId": 0,
        "deviceName": "Cortex Example PDU 4B-5C",
        "setupLocked": 0,
        "httpsEnable": false,
        "modbusTCPEnable": true,
        "modbusTLSEnable": false,
        "webAuthEnable": false,
        "accessBanner": "NOTICE: Authorized use only. Activity on this device is recorded."
      }
    }
    ```

    To change only the network settings, include only the `ipv4` section:

    ```text
    {
      "ipv4": {
        "enable": true,
        "dhcpEnable": false,
        "address": "192.168.7.3",
        "gateway": "192.168.7.1",
        "subnetMask": "255.255.255.0",
        "dns1": "8.8.8.8",
        "dns2": "0.0.0.0",
        "ntpIpAddress": "0.0.0.0",
        "ntpURL": "time.windows.com"
      }
    }
    ```
  </Accordion>

  <Accordion title="**Uploading Configuration Files**" icon="upload">
    Configuration files can be uploaded from a USB drive or from the web console.

    ### **Uploading via USB**

    #### **Preparing the USB Drive**

    1. Use a USB drive of 32 GB or less, formatted FAT32.
    2. Place the configuration file in the root directory of the drive, not inside a folder.
    3. Only one configuration file may be in the root directory. Other configuration files must be moved into a folder so they are not read.
    4. Confirm the file name uses an accepted prefix and extension. See **Downloading Configuration Files** above.

    #### **Applying the Configuration**

    1. Insert the USB drive into the USB port on the monitor.
       <img
         src="/images/USB-PORT-2-1.png"
         alt="USB PORT 2"
         title="USB PORT 2"
         style={{ width:"31%" }}
       />
    2. Press and holding the reset button for 6 seconds until the status light turns solid green, then release.
    3. Wait while the monitor reads the drive.
    4. When the status light blinks rapidly orange and red, the configuration file has been detected. Press the reset button once, quickly, to confirm.
    5. The status light blinks green at 1 Hz when the update is complete.

    <Note>
      Do not hold the reset button for longer than 10 seconds as it restores the IP address to default.
    </Note>

    <Note>
      If a firmware file is also on the drive, the status light blinks green and blue first. Do not press the reset button during this cycle unless you intend to update the firmware.
    </Note>

    </Warning>

    #### **Preparing the USB Drive**

    1. Use a USB drive of 32 GB or less, formatted FAT32.
    2. Unzip the firmware file and place it in the root directory of the drive, not inside a folder.
    3. Remove any configuration files from the root directory unless you intend to apply them. Confirm behavior when both file types are present.

    | Update Type | File Name |
    | :-- | :-- |
    | Firmware | `CortexFW_x.xx.bin` Confirm naming format. |

    #### **Applying the Firmware**

    1. Insert the USB drive into the USB port on the monitor.
       <img
         src="/images/image-48.png"
         alt="Image"
         title="Image"
         style={{ width:"31%" }}
       />
    2. Reboot the monitor by power cycling it, or by pressing and holding the reset button for 5 to 10 seconds until the status light turns solid green, then release.
    3. When the status light blinks green and blue, the firmware file has been detected. Press the reset button once, quickly, to begin programming.
    4. The status light blinks blue while programming. This takes approximately three minutes.
    5. The status light blinks green at 1 Hz when the update is complete.

    If the reset button is not pressed while the firmware file is detected, the monitor starts normally without updating. The sequence can be repeated.

    <Warning>
      Do not remove the USB drive or interrupt power while programming is in progress.
    </Warning>

  <Accordion title="**Recovering Lost IP Address**" icon="usb-drive" iconType="regular">
    If the IP address of a monitor is unknown, it can be read from a USB drive without changing any settings.

    1. Insert a USB drive of 32 GB or less, formatted FAT32, into the USB port while the monitor is powered.
    2. Wait approximately 10 seconds.
    3. Remove the drive and open the IP settings file on a PC. <br />ip_settings.json
    4. The file lists the monitor’s current IP address, subnet mask and gateway.

    If the IP address cannot be recovered this way, the monitor can be reset to the default IP address of 192.168.7.3. This also erases all other settings. 
  </Accordion>

  <Accordion title="**Connecting to the Web Console**" icon="window-flip" iconType="regular">
    The web console is used to view readings, configure the monitor and update firmware. It is accessed from any browser.

    #### **Physical Connection**

    - Both ports share a common IP address
    - Network Switch: Connect ethernet Port 2 on the monitor to a network switch, then connect the PC to the same switch or network.
    - Direct Connect: Connect a PC directly to ethernet Port 2 on the monitor. Disconnect any ethernet cable from Port 1 so other devices on the network can't interfere with the connection.

    <Note>
      Do not connect to a Flex Port. The four Flex Ports use similar RJ45 jacks but are for CT interface devices only.
    </Note>

    #### **Setting the PC IP Address**

    The PC must be on the same subnet as the monitor. <br />For a monitor at the default address of 192.168.7.3

    1. Open the Ethernet adapter settings on the PC.
    2. Set a static IP address such as `192.168.7.10`, with subnet mask `255.255.255.0`.
    3. Confirm no other device on the network uses the same address as the monitor or the PC.

    #### **Opening the Console**

    1. Enter the monitor IP address in the browser address bar, e.g.<br />Default: `http://192.168.7.3`<br />HTTPS Enabled: `https://192.168.7.3`
    2. The main page of the web console appears, showing device information and the installed firmware version.

    #### **Troubleshooting**

    - If the IP address is unknown, see **Recovering Lost IP Address** above.
    - If the console does not load, disconnect the monitor from the main network and connect directly from the PC to rule out an IP conflict.
  </Accordion>

  <Accordion title="**Using REST APIs to View Data**" icon="rectangle-api">
    The Cortex monitor provides a REST API for reading meter data over HTTP. Responses are returned in JSON format. No authentication is required. For the full endpoint reference, see

    #### **Requirements**

    - Network access to the monitor. See **Connecting to the Web Console** above.
    - A tool capable of HTTP requests, such as a browser, `curl` or a scripting language.

    #### **Making a Request**

    All requests use the format:

    ```text
    http://<device-ip>/api/<endpoint>
    ```

    To test the connection, enter the following in a browser. A response with `"data": 1` confirms the monitor is reachable.

    ```text
    http://192.168.7.3/api/healthcheck
    ```

    #### **Common Endpoints**

    | Endpoint | Returns |
    | :-- | :-- |
    | `/api/deviceinfo` | Serial number, model, firmware version, connected cards |
    | `/api/volts` | Voltage, frequency and voltage alarm status for V1 and V2 |
    | `/api/current` | RMS current per circuit |
    | `/api/kw` | Real power per circuit |
    | `/api/kwh` | Cumulative energy per circuit |
    | `/api/alarms` | Alarm status per circuit |
    | `/api/breakerutilization` | Breaker utilization % per circuit |
    | `/api/flexmeter` | Grouped per-circuit and total readings for flex meters |
    | `/api/aggregatemeter` | Grouped readings for aggregate meters |
    | `/api/help` | List of all endpoints supported by the installed firmware |

    #### **Selecting Circuits**

    Per-circuit endpoints return all 192 circuits by default. Use `?id=N` for a single circuit or `?start=N&end=M` for a range.

    ```text
    curl http://192.168.7.3/api/kw?start=1&end=4
    ```

    ```text
    {
      "endpoint": "/api/kw",
      "url": "http://192.168.7.3/api/kw",
      "data": {
        "dataType": "kw",
        "readings": {
          "circuit_1": 0.0258,
          "circuit_2": 0.0131,
          "circuit_3": 0.0259,
          "circuit_4": 0.0132
        }
      }
    }
    ```

    **!**Endpoints and field names may change between firmware versions. Test any integration (SCADA, BMS, dashboards) after each firmware update.

    **Resetting the IP Address Using the Reset Button**

    **!**A factory reset restores **all** settings to factory default, not only the IP address. Download the configuration first if possible. See **Downloading Configuration Files** above.

    1. With the monitor powered, press and hold the reset button for more than 10 seconds. 
    2. The status light turns solid green at around 5 seconds. Continue holding.
    3. Release the button when the status light turns solid orange. All settings have been restored to factory default.
    4. Connect to the monitor at the default IP address of 192.168.7.3. See **Connecting to the Web Console** above.
    5. Set the required IP address and restore the configuration by uploading the saved configuration file. See **Uploading Configuration Files** above.

    #### **Default Network Settings**

    | Setting | Default |
    | :-- | :-- |
    | IP Address | 192.168.7.3 |
    | Subnet Mask | 255.255.255.0 |
    | Gateway | 192.168.7.1 |
    | DHCP | Disabled |
  </Accordion>
