This page describes each physical interface on the CSM-1-00 and CSM-2-00.

## Interface Summary

| Interface | Type | Function | Notes |
| --- | --- | --- | --- |
| DC connector | Terminal connector | Energizes the monitor | Ground (earth) for both AC and DC is connected through the DC connector |
| Volt Input 1 | Terminal connector | AC reference voltage sensing, L1/L2/L3 | Sensing only, no power draw |
| Volt Input 2 | Terminal connector | Second AC reference voltage input | CSM-2-00 only |
| Flex Ports 1–4 | RJ45 | CT modules, CT strips, Multi-Cards | Up to 48 current channels per port |
| AUX port | RJ45 | Digital Input, Digital I/O + Serial, and Thermal modules | Up to 8 modules, 500 mA total |
| Ethernet Ports 1 and 2 | RJ45 | Network: web console, REST API, Modbus TCP | Common IP address; default 192.168.7.3 |
| USB port | USB | Configuration files, firmware, IP settings readout | 32 GB or less, FAT32 |
| Reset button | Push button | Apply USB updates; restore factory defaults | Hold >10 s = factory reset |
| Status LED | Multi-color LED | Operating and update status | See below |

## AC Reference Voltage Inputs

The AC reference voltage inputs are for sensing only and draw no power. Fuse according to code, 0.25 A up to the maximum conductor rating. Each input measures L1, L2, and L3, providing line-to-neutral and line-to-line voltage, THD, phase angle, and frequency. Volt Input 2 is available on the CSM-2-00 only; on the CSM-2-00, each circuit can be assigned to a phase of either input.

<Warning>
  AC wiring has lethal voltages. Installation must be completed by a qualified person.
</Warning>

## Flex Ports and AUX Port

<Info>
  Flex Ports and the AUX port use RJ45 jacks similar to the Ethernet ports. Connect Flex Port modules (CT modules, CT strips, Multi-Cards) only to Flex Ports, AUX modules only to the AUX port, and the network only to Ethernet Port 1 or 2.
</Info>

### Flex Ports

Each Flex Port supports a daisy chain of CT modules or CT strips for up to 48 current channels. Connect the Flex Port to the **IN** port of the first device and **OUT** to **IN** for each following device. The Flex Port used determines register assignment; start with Flex Port 1.

### AUX Port

The AUX port supports up to 8 daisy-chained modules (firmware 2.9.1 or later; 4 on earlier firmware), with a combined current draw of no more than 500 mA. The order of modules in the chain determines their register assignments.

## Ethernet Ports

Two RJ45 Ethernet ports share a common IP address. Connect either port to a PC or network switch. The default IP address is `192.168.7.3` (subnet mask 255.255.255.0, gateway 192.168.7.1, DHCP disabled). The polling device must be on the same subnet.

## USB Port

- Insert a USB drive (32 GB or less, FAT32) while the monitor is powered and wait about 5 seconds: the monitor writes its IP settings file to the drive.
- Configuration files and firmware files are loaded from the root directory of the drive using the reset button sequence. See [Uploading Configuration Files](/configuration/uploading-files) and [Update via USB](/firmware/update-via-usb).

## Reset Button

| Action | Result |
| --- | --- |
| Hold 5 to 10 seconds until the status LED is solid green, then release | Reboots the monitor and checks the USB drive for configuration or firmware files |
| Press once while a USB file is detected | Applies the configuration or starts firmware programming |
| Hold more than 10 seconds | Restores **all** settings, including the IP address, to factory default (solid orange) |

## Status LED

| Indication | Meaning |
| --- | --- |
| Green blink (1 Hz) | Status good / update complete |
| Solid green | Reset sequence accepted; release the button |
| Rapid orange and red blink | Configuration file detected |
| Green and blue blink | Firmware file detected |
| Blue blink | Firmware programming in progress |
| Solid orange | Factory default restored |
