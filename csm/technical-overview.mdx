**192 Circuit Advanced Power Quality Monitor**

The Cortex CSM Multi-Circuit Power Quality Monitor is a single solution for critical power monitoring applications. One centralized CSM module works with a growing family of application-specific interface modules.

| Model | Description |
| --- | --- |
| CSM-1-00 | Single voltage input |
| CSM-2-00 | Dual voltage input |

## Power Quality Metering per Circuit

In addition to the features expected on high-end power quality monitors, the CSM is designed for ultra high-density critical power distribution. Real-time, high-resolution data and power quality accuracy enable analytics that help you monitor and optimize high-density data centers.

## Easy to Install, Easy to Use

Deployment uses plug-and-play graphical configuration. Optional centralized data aggregators auto-adopt hundreds of monitors and log, report, and export data centrally. A customized user development environment is available for advanced analytics.

## Features

- Supports 192 circuits
- 0.2% accuracy
- High-resolution power quality sampling per channel
- HTTPS, IPv4, and IPv6
- Compact, space-saving design
- Single and dual voltage reference models
- Technology and feature upgrades
- Graphical configuration
- Multiple protocols: Modbus TCP/IP, REST API, SNMP\*, BACnet\*, MQTT\*
- Plug-and-play consolidator to minimize port requirements
- Optional multi-point thermal monitoring
- Onboard data logging\*
- Upgradeable technology modules
- CBEMA/ITIC capture and logging
- Automatic waveform capture per channel
- Detailed power quality analytics
- Multiple display options

\* Pending release

## User Interface

The web console displays data according to the physical construction of the monitored equipment.

- **Dashboard** — view and manage circuits by physical location and friendly name. Flex Port and Digital Flex Port panels show port status, friendly name, and alerts.
- **Single line diagrams** — create active single line diagrams that match the equipment layout.
- **Power quality analytics** — waveform captures, phasor diagrams, and harmonic content help you diagnose issues.
- **Custom web pages** — product-specific web pages can be developed for OEMs (OEM only).
- **Event log** — exportable logs capture alarms and changes of state, such as digital input contact changes and over voltage events.
- **Data logging** — exposes trends and issues over time.
- **Panel configuration** — configure systems according to their exact layout: panel type, strip orientation, and strip wiring.
- **Register Reveal** — shows the Modbus register for each circuit's selected metric, which simplifies integration. See the [Modbus Register Map](/modbus/register-map).

## System Overview

### AUX Port

The AUX port hosts auxiliary modules connected in series, including:

- Thermal monitoring module
- Serial interface
- Digital input / output module
- Displays

<Note>
  The datasheet lists up to 4 AUX modules. Firmware 2.9.1 or later supports up to 8 modules, provided their combined current draw does not exceed 500 mA. See [AUX Port Modules](/aux-modules/overview).
</Note>

### Flex Ports and Current Inputs

Each of the four Flex Ports hosts up to 48 current channels, for a total of 192 circuits per monitor. Two 24-CT modules can be daisy-chained on each Flex Port. Supported Flex Port modules:

- [Solid core CT strips](/flex-modules/solid-core-ct-strips)
- [Busway monitors](/flex-modules/busway-card)
- [CT interface cards](/flex-modules/ct-card)

### Dual Voltage Version

The CSM-2-00 has two separate voltage references, which makes it ideal for PDU and dual input RPP applications. You can assign each current channel to either voltage source. For example, assign PDU input circuits to Voltage Input 2 and PDU output circuits to Voltage Input 1.

## Interface

Both models share the same connections. The CSM-2-00 adds a second voltage input.

| Connection | Description |
| --- | --- |
| DC Input | 12–24 VDC power supply input |
| USB Port | Flash drive configuration, logging, and firmware updates |
| AUX Port | Connects peripherals in series, including DI/DO, thermal modules, and displays |
| Smart Button | Labeled **RESET** on the unit |
| Status Light | Device status LED. See the [Quick Reference](/quick-reference#status-led) |
| Ethernet 1 and 2 | Dual Ethernet ports |
| Voltage Input | L1, L2, L3, N, and ground (CSM-1-00) |
| Voltage Input 1 and 2 | Two independent voltage references (CSM-2-00 only) |
| Flex Ports 1–4 | 48 current channels per port, 4 ports |

For details on each connection, see [Interfaces](/csm/interfaces).
