The CSM-1-00 and CSM-2-00 are the monitors at the center of the Cortex PQM system. The monitor measures AC reference voltage, collects current readings from CT modules and CT strips on its Flex Ports, collects digital and temperature data from modules on its AUX port, and makes all data available over Ethernet through a web console, REST API, and Modbus TCP.

## Model Comparison

| Feature | CSM-1-00 | CSM-2-00 |
|---|---|---|
| Voltage inputs | 1 (Volt Input 1) | 2 (Volt Input 1 and Volt Input 2) |
| Voltage phases per input | L1, L2, L3 | L1, L2, L3 |
| Circuit voltage assignment | Input 1 L1–L3 | Input 1 L1–L3 or Input 2 L1–L3 |
| Flex Ports | 4 (up to 48 current channels each) | 4 (up to 48 current channels each) |
| Maximum circuits | 192 | 192 |
| AUX port | Yes (up to 8 modules) | Yes (up to 8 modules) |
| Ethernet | 2 ports, common IP address | 2 ports, common IP address |
| USB port | Yes | Yes |

## Ports and Controls

- **DC connector** — energizes the monitor. The ground (earth) connection for both AC and DC is made through the DC connector.
- **AC reference voltage inputs** — sensing only, no power draw. Volt Input 2 is on the CSM-2-00 only.
- **Flex Ports 1–4** — RJ45 ports for CT modules, CT strips, and Multi-Cards.
- **AUX port** — RJ45 port for Digital Input, Digital I/O + Serial, and Thermal modules.
- **Ethernet Ports 1 and 2** — network connection; both ports share a common IP address (default `192.168.7.3`).
- **USB port** — configuration files, firmware updates, and IP settings readout (32 GB or less, FAT32).
- **Reset button** — used to apply USB updates and to restore factory defaults.
- **Status LED** — see the [Quick Reference](/quick-reference#status-led).

## Expansion

**Flex Ports** — Each of the four Flex Ports supports a daisy chain of CT modules or CT strips for up to 48 current channels. The Flex Port used determines register assignment.

**AUX Port** — Up to 8 AUX modules can be daisy-chained (firmware 2.9.1 or later; 4 on earlier firmware), provided their combined current draw does not exceed 500 mA.

Modules connect with standard Ethernet cables and are powered through the cable; no separate power supply is required for the modules.

## Communication

- **Web console** — view readings, configure the monitor, and update firmware from any browser.
- **REST API** — JSON over HTTP (HTTPS optional). See the [REST API Reference](/api/overview).
- **Modbus TCP** — port 502, up to 15 concurrent clients. See the [Modbus Register Map](/modbus/register-map).

The default IP address is `192.168.7.3` with DHCP disabled. The address can be changed in the web console or configuration file.
