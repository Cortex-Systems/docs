Each voltage input on the Cortex PQM measures three phases (L1, L2, L3), reporting line-to-neutral and line-to-line voltages. The CSM-1-00 has one voltage input (Volt Input 1); the CSM-2-00 has two (Volt Input 1 and Volt Input 2). The voltage input configuration must match the service being monitored.

<Warning>
  AC wiring has lethal voltages. Installation must be completed by a qualified person. If you are unsure of the wiring configuration of your panel, consult a qualified electrician before proceeding.
</Warning>

## Voltage Input Settings

Configure each voltage input in the web console (**Configuration > Meter Config**) or in the `voltage` section of the configuration file:

| Setting | Description |
| --- | --- |
| System voltage | Line-to-line system voltage, for example `208` |
| PT ratio | Potential transformer ratio, where `100` = 1.00 |
| Frequency | System frequency, 40–70 Hz (for example `60`) |
| Phase rotation | `ABC` or `ACB` |

Select the service type and voltage reference that match the installation in the web console.

## Measured Voltages

| Measurement | Phases |
| --- | --- |
| Line-to-neutral voltage | L1, L2, L3, and average |
| Line-to-line voltage | L12, L23, L31, and average |
| Voltage THD (line-to-neutral) | L1, L2, L3 |
| Voltage THD (line-to-line) | Computed for L1 (the L12 reference phase) |
| Phase angle | L1, L2, L3, referenced to L1 |
| Frequency | Derived from Line 1 |
| Voltage unbalance | NEMA line voltage unbalance rate (LVUR) |

## Circuit Phase Assignment

Each circuit is assigned to a voltage phase so that power, energy, and power factor are calculated against the correct voltage:

| Value | CSM-1-00 | CSM-2-00 |
| --- | --- | --- |
| 0 | Input 1 L1 | Input 1 L1 |
| 1 | Input 1 L2 | Input 1 L2 |
| 2 | Input 1 L3 | Input 1 L3 |
| 3 | – | Input 2 L1 |
| 4 | – | Input 2 L2 |
| 5 | – | Input 2 L3 |

The CSM-2-00 lets you assign each circuit to either voltage input, so a single monitor can measure, for example, both PDU input and PDU output.

## Neutral Current

The monitor calculates neutral current when the voltage inputs are connected, so a neutral CT is not required.

## Phase Settings

| Setting | Options |
| --- | --- |
| Phase mode | Relative: phase angles are relative to the assigned voltage phase. Absolute: all phase angles are referenced to VA = 0° |
| Angle range | Signed: −180° to +180°. Unsigned: 0° to 360° |

For AC wiring and fusing, see the [AC Wiring Guide](/wiring/ac-wiring).
