The Cortex PQM supports several standard AC wiring configurations used in residential, commercial, and industrial electrical systems. The configuration you select must match the actual wiring of the circuit or panel you are monitoring. Selecting the correct configuration ensures that the device measures voltage, current, and power accurately and that calculated values such as power factor and energy are meaningful.

<Warning>
  **Only use the configurations listed on this page.** Wiring the device for a configuration not listed here, or selecting a configuration that does not match the actual circuit wiring, may damage the device or produce inaccurate measurements. If you are unsure of the wiring configuration in your panel, consult a qualified electrician before proceeding.
</Warning>

## Supported Configurations

### Single-Phase 2-Wire (1P2W)

| Parameter | Value |
|---|---|
| Common name | Single-phase 2-wire |
| Conductors | 2 (1 line, 1 neutral) |
| Nominal voltage | 120V line-to-neutral |
| Compatible model | CSM-1-00, CSM-2-00 |
| Voltage inputs used | L1, N |
| CT inputs required | 1 (on L1) |

This is the simplest configuration, used for standard single-phase 120V circuits. One CT is required on the line conductor. The neutral conductor connects to the N terminal for voltage reference.

---

### Single-Phase 3-Wire / Split-Phase

| Parameter | Value |
|---|---|
| Conductors | 4 (3 lines, 1 neutral) |
| Nominal voltage | 208-480V |
| Voltage inputs used | L1, L2, L3, N |
| CT inputs required | 3 (one per line) |

Split-phase service is common in North American residential panels. Two line conductors are 180° out of phase with each other, sharing a common neutral. Both line conductors must be terminated at L1 and L2 respectively. Two CTs are required — one on each line conductor. **The CSM-1-00 does not support this configuration.**

---

### Three-Phase 3-Wire Delta (3P3W)

| Parameter | Value |
|---|---|
| Common name | Three-phase delta, 3-wire delta |
| Conductors | 3 (3 lines, no neutral) |
| Nominal voltage | 208V or 480V line-to-line |
| Compatible model | CSM-2-00 only |
| Voltage inputs used | L1, L2, L3 |
| CT inputs required | 3 (one per line) |

Three-phase delta configurations are used in industrial and commercial systems where no neutral conductor is present. All three line conductors terminate at L1, L2, and L3. Three CTs are required. Voltage measurements are line-to-line only; no line-to-neutral voltage is available. **The CSM-1-00 does not support this configuration.**

---

### Three-Phase 4-Wire Wye (3P4W)

| Parameter | Value |
|---|---|
| Common name | Three-phase wye, 4-wire wye |
| Conductors | 4 (3 lines, 1 neutral) |
| Nominal voltage | 120/208V or 277/480V |
| Compatible model | CSM-2-00 only |
| Voltage inputs used | L1, L2, L3, N |
| CT inputs required | 3 (one per line) |

Three-phase 4-wire wye is the most common configuration for commercial and industrial distribution panels. All three line conductors and the neutral terminate at their respective terminals. Three CTs are required, one on each line conductor. Both line-to-neutral and line-to-line voltages are measured. **The CSM-1-00 does not support this configuration.**

---

## Configuration Selection Summary

| Configuration | Model | Lines | Neutral | CTs Required |
|---|---|---|---|---|
| 1P2W — Single-phase 2-wire | CSM-1-00 or CSM-2-00 | 1 | Yes | 1 |
| 1P3W — Split-phase | CSM-2-00 only | 2 | Yes | 2 |
| 3P3W — Three-phase delta | CSM-2-00 only | 3 | No | 3 |
| 3P4W — Three-phase wye | CSM-2-00 only | 3 | Yes | 3 |

For detailed wiring diagrams showing terminal assignments and CT placement for each configuration, see the [AC Wiring Guide](/wiring/ac-wiring).
