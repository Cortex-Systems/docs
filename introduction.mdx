The Cortex PQM is a DIN-rail mounted power quality monitor designed for installation inside electrical panels, PDUs, and distribution equipment. It measures voltage, current, power, energy, power factor, and harmonic distortion (up to the 63rd voltage harmonic) on up to 192 circuits, and makes the data available over ethernet through a web console, REST API, and Modbus TCP.

Both models share the same form factor, port layout, and software interfaces. The CSM-2-00 adds a second voltage input; each circuit can be assigned to a phase of either Volt Input 1 or Volt Input 2.

## What the Cortex PQM Measures

- **Voltage** — line-to-neutral and line-to-line voltage, voltage THD, phase angle, frequency, and voltage unbalance for each voltage input
- **Current** — RMS current per circuit from 0.333 V output current transformers
- **Power** — real (kW), reactive (kVAR), and apparent (kVA) power per circuit
- **Energy** — cumulative kWh, kVARh, and kVAh per circuit, plus a resettable kWh accumulator
- **Power quality** — power factor, phase angle, crest factor, and current THD per circuit
- **Harmonics** — up to 63 voltage harmonics per phase and 21 current harmonic values per circuit
- **Demand** — kW demand and current demand over a configurable demand interval
- **Events** — CBEMA/ITIC voltage sag, swell, and dropout events, and AC waveform capture

## Key Capabilities

**Flex Ports** Four Flex Ports connect CT modules and CT strips using standard Ethernet cables. Each Flex Port supports up to 48 current channels, for up to 192 circuits per monitor.

**AUX Port** The AUX port connects daisy-chained digital input, digital I/O + serial, and thermal modules.

**Circuit grouping** Circuits can be grouped into up to 96 Flex Meters (up to 3 circuits each, one per phase) and 8 Aggregate Meters.

**Modbus TCP** For integration with PLCs, SCADA, BMS, and energy management systems. See the [Modbus Register Map](/modbus/register-map).

**REST API** JSON over HTTP for dashboards, SCADA, BMS, and custom applications. See the [REST API Reference](/api/overview).

## How It Connects

The Cortex PQM mounts on a standard 35 mm DIN rail. A DC power source energizes the monitor, and the ground (earth) connection for both AC and DC is made through the DC connector. The AC reference voltage inputs are for sensing only and draw no power. Current is measured with 0.333 V output CTs connected to CT modules or CT strips on the Flex Ports. Two Ethernet ports, which share a common IP address, provide access to the web console, REST API, and Modbus TCP. The default IP address is `192.168.7.3`

## Typical Use Cases

- **Branch circuit and PDU monitoring**  per-circuit current, power, energy, and breaker utilization
- **Sub-metering**  allocate energy to tenants, loads, or equipment groups using Flex Meters and Aggregate Meters
- **BMS and SCADA integration**  real-time data via Modbus TCP or the REST API
- **Power quality analysis**  harmonics, power factor, voltage sags and swells, and phase imbalance
