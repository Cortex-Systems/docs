When CS18-01-TMP Thermal modules are connected to the AUX port, their RTD temperatures are available in the AUX port **RTD Temperature** register block. The same block is shared by all AUX port RTD channels.

See [Thermal Module Installation](/aux-modules/thermal-module) for hardware setup.

## Data Format

| Setting | Value |
|---|---|
| Data type | FLOAT32 (2 registers per value) |
| Temperature unit | °C |
| Register block | 2884–3267 (RTD Temperature #1–#192) |
| Invalid reading | `999.99` = sensor not connected or out of range (as reported by the REST API) |

## RTD Temperature Registers

| Register | Description |
| --- | --- |
| 2884–2885 | RTD Temperature #1 |
| 2886–2887 | RTD Temperature #2 |
| 2888–2889 | RTD Temperature #3 |
| … | Each following RTD uses the next 2 registers |
| 3266–3267 | RTD Temperature #192 |

To locate RTD temperature _n_, read 2 registers starting at `2884 + 2 × (n − 1)`.

## AUX Port Status Registers

Use these registers to confirm which cards are connected and in what order. Card 1 is the card plugged directly into the AUX port; every device on the AUX port counts as a card.

| Register | Type | Description |
| --- | --- | --- |
| 1000 | UINT16 | Port status (0 = OK, 1 = Discovery) |
| 1001 | UINT16 | Number of devices connected |
| 1002–1009 | UINT16 | Device status, cards 1–8 |
| 1018–1025 | UINT16 | Device type, cards 1–8 |
| 1034–1041 | UINT16 | Device firmware version, cards 1–8 |
| 1050–1065 | UINT32 | Device serial number, cards 1–8 |

## REST Alternative

`GET /api/auxport` returns each Thermal board with `"deviceType": "thermal"`, RTD sensor channels 1–18, and the board temperature on channel 19. See the [REST API Reference](/api/overview).
