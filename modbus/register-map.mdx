Register numbers below are as listed in the Cortex register map.

## Data Types

| Type | Size | Description |
| --- | --- | --- |
| `UINT16` | 1 register | Unsigned 16-bit integer |
| `UINT32` | 2 registers | Unsigned 32-bit integer |
| `FLOAT32` | 2 registers | 32-bit floating point |
| `CHAR` | 2 characters per register | Text (for example, 40 characters = 20 registers) |
| `BITS` | 1 register | Bit field or 0/1 value |

**R/W:** `W` = writable, `NV` = non-volatile.

<Note>
  Register map revision history: A/B (firmware 1.3.8), C (1.4.0, line-to-line THD), D (1.5.0, Aggregate Meter and voltage unbalance), E (1.6.0, VP bit, resettable kWh), F (2.11, HTTPS/Modbus TCP/Modbus TLS enable, phase mode, angle range, AUX and Flex Port DI/DO/RTD), G (2.11.6, CBEMA/ITIC event counters).
</Note>

## Aggregate Meters and Flex Meters (38000–63999)

Each meter occupies a 250-register block:

| Registers | Meter |
| --- | --- |
| 38000–39999 | Aggregate Meters #1–#8 (38000 + 250 × (n − 1)) |
| 40000–63999 | Flex Meters #1–#96 (40000 + 250 × (n − 1)) |

Layout within a meter block (offsets shown for the block starting at 40000):

| Offset | Description |
| --- | --- |
| +0 to +9 | Meter name (20 characters) |
| +10 | Meter mode: 0 = unused, 1 = Flex Meter, 2 = PDU Meter, 3 = Aggregate Meter |
| +11 to +14 | Number of circuits assigned; assigned circuits (Aggregate Meter: circuits per L1/L2/L3) |
| +15 to +23 | CT size, breaker size, and voltage phase for circuits 1–3 |
| +24 to +27 | Alarm status: summary and circuits 1–3 |
| +50 to +81 | Summary: total kWh, resettable kWh, kVARh, VAh, kW, kVAR, kVA, instantaneous max current, neutral current, power factor, max utilization, max total kW, max total current, max circuit utilization, max neutral current |
| +100 to +131 | Circuit #1 (Aggregate Meter: L1): kWh, resettable kWh, kVARh, kVAh, kW, kVAR, kVA, current, PF, phase angle, THD, crest factor, breaker utilization, max kW, max current, max utilization |
| +150 to +181 | Circuit #2 (Aggregate Meter: L2) |
| +200 to +231 | Circuit #3 (Aggregate Meter: L3) |
